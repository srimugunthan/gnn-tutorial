Lesson 1

Why Graphs? What Graphs Encode

You already know how CNNs exploit the grid structure of images and RNNs exploit the sequential structure of text. GNNs are the answer to a natural question: what if the data has neither grid nor sequence structure, but relational structure?

A graph is a triple

A graph G = (V, E, u) consists of:

  • Nodes (vertices) V — the entities
  • Edges E ⊆ V × V — the relationships between entities
  • Global attributes u — properties of the entire graph

Each component carries a feature vector:

  • Node features: a matrix X ∈ ℝ|V| × dv
  • Edge features: a matrix E ∈ ℝ|E| × de
  • Global features: a vector u ∈ ℝdu
Key idea: A graph encodes what things are (node/edge features) separately from how they relate (connectivity structure). This separation is what makes graphs powerful — the same GNN architecture works whether a molecule has 5 atoms or 50.

Data you already know, reframed as graphs

The insight is that grids and sequences are special cases of graphs:

Data Nodes Edges Structure
Image Pixels Adjacency (4 or 8 neighbors) Regular grid
Text Tokens Sequential links Chain
Molecule Atoms Bonds Irregular
Social network People Friendships Irregular, scale-free
Citation network Papers Citations Directed, irregular
Analogy: A CNN is a GNN on a grid graph with weight-sharing across the spatial kernel. An RNN is a GNN on a chain graph with weight-sharing across time steps. GNNs generalise both to arbitrary topologies.

Why not just flatten it?

You might ask: why not represent the adjacency matrix as a flat vector and feed it into an MLP? Three reasons:

  1. Variable size. Graphs vary in node count. An MLP needs a fixed input dimension. You'd need padding, which wastes parameters and doesn't generalise.
  2. Permutation sensitivity. The same graph can be represented by any reordering of its adjacency matrix. An MLP would treat each reordering as a different input. A GNN is permutation invariant (or equivariant) by design.
  3. No structural inductive bias. An MLP doesn't know that node 3 and node 7 are neighbors. A GNN's operations are defined by the connectivity, so it naturally respects the structure.
Key idea: The defining property of a GNN is permutation equivariance — reordering the nodes produces the same reordering in the output, rather than a completely different result. This is the graph analogue of translation equivariance in CNNs.

Three levels of prediction

GNNs can make predictions at three levels, each requiring a different output head:

  1. Node-level: classify each node (e.g., predict the role of a protein in a PPI network)
  2. Edge-level: predict a property per edge (e.g., does a link exist? what type of bond?)
  3. Graph-level: predict a property of the whole graph (e.g., is this molecule toxic?)

The architecture stays mostly the same — only the final pooling/readout step changes. We'll cover this in detail in a later lesson.

Check your understanding

1. A social network where users have profile features and friendships have a "since" date. What carries the "since" date?

  • Node feature vector
  • Edge feature vector
  • Global feature vector
  • Adjacency matrix entry
The "since" date is a property of the relationship between two users, so it belongs to the edge feature vector. The adjacency matrix only stores connectivity (0 or 1), not rich attributes.

2. Why is permutation equivariance important for a GNN?

  • It reduces the parameter count of the model
  • It allows the model to handle directed edges
  • It ensures the output is independent of arbitrary node ordering
  • It enables the model to process variable-length sequences
Graphs have no canonical node ordering. Two isomorphic graphs should produce the same predictions regardless of how the nodes are indexed. Permutation equivariance guarantees this — reorder the input, and the output reorders consistently.

3. Predicting whether a molecule is soluble in water is an example of which prediction level?

  • Node-level prediction task
  • Edge-level prediction task
  • Graph-level prediction task
  • Subgraph-level prediction
Solubility is a property of the entire molecule, not of any single atom or bond. This requires graph-level prediction: pool all node representations into a single graph representation, then classify.
