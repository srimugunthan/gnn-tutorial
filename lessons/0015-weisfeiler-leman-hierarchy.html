Lesson 15

The Weisfeiler-Leman Hierarchy

Back in Lesson 10, GIN was motivated by a claim: it's as powerful as the Weisfeiler-Leman (WL) test at telling graphs apart. We took that on faith to get to the architecture. This lesson cashes out the claim — what the WL test actually is, why message passing turns out to be doing the same computation, and what "as powerful as 1-WL" implies about the hard ceiling on any standard GNN's ability to distinguish graphs, no matter how it's trained or how many layers it has.

Expressiveness is about telling graphs apart

A GNN is, structurally, a function that maps a graph to a set of embeddings. Call two graphs indistinguishable by a GNN if it maps them (or corresponding nodes in them) to identical embeddings, for every possible choice of weights. "Expressiveness" is a question about the function class: which pairs of non-isomorphic graphs can some GNN in this class map to different embeddings, and which pairs can no GNN in the class ever separate, regardless of training?

This is a statement about representational capacity, not about what a specific trained model happens to learn — the same flavor of question as "can an MLP with ReLUs represent XOR," just for graph-structured inputs.

Key idea: Expressiveness ceilings are architecture properties, not training artifacts. If two non-isomorphic graphs are indistinguishable to the GNN's function class, no amount of data or optimization will ever separate them — the information was destroyed by the architecture itself.

The 1-WL color-refinement algorithm

The Weisfeiler-Leman test (1-dimensional version, also called color refinement) is a classical, cheap heuristic for graph isomorphism. In outline:

  1. Initialize every node's "color" from its label or degree.
  2. Refine: repeatedly recolor each node by hashing its current color together with the multiset of its neighbors' colors.
  3. Stop when the coloring stops changing (the partition is stable).
  4. Compare: two graphs are declared possibly-isomorphic if their final color histograms match; if the histograms differ, the graphs are definitely non-isomorphic.

The full step-by-step mechanics, with two worked examples, live in the WL Test Reference — read it alongside this lesson if the algorithm above feels abstract.

Message passing is color refinement, learned

Look again at the gather → aggregate → update loop from Lesson 4 and set it side by side with the steps above:

1-WL color refinement Message-passing GNN
Initial color from node label/degree Initial hidden state hv(0) from node features
Gather multiset of neighbor colors Gather multiset of neighbor hidden states (AGGREGATE)
Hash(own color, neighbor multiset) Learned COMBINE/UPDATE function
Compare final color histograms Pooled/readout graph embedding (Lesson 12)

They're the same algorithm skeleton. The WL hash function is a fixed, injective (but otherwise arbitrary) recoloring rule; a GNN replaces it with a learned AGGREGATE + COMBINE. Xu et al. (2019) make this precise: for any message-passing GNN, if the GNN maps two graphs to different embeddings, then 1-WL also distinguishes them. In other words, a message-passing GNN's discriminative power is bounded above by 1-WL — no message-passing architecture, however deep or wide, can ever tell apart two graphs that 1-WL says are indistinguishable.

Key idea: 1-WL isn't just an analogy for message passing — it's an upper bound on what message passing can ever compute, provably, for the entire architecture family (GCN, GraphSAGE, GAT, GIN, and any future variant built on gather-aggregate-update).

GIN reaches the ceiling

The bound above says GNNs are at most as powerful as 1-WL. Whether a specific GNN actually reaches that ceiling depends on whether its AGGREGATE and COMBINE steps are injective over multisets of neighbor features — if two different neighbor multisets ever get squashed to the same aggregated value, the GNN has thrown away information 1-WL would have kept.

This is exactly the design problem GIN (Lesson 10) solves. Xu et al. show that sum aggregation, followed by an MLP, can represent an injective function over any countable multiset domain — the "deep multisets" result. Mean and max aggregation cannot: mean conflates a neighbor multiset {1, 1} with {1} rescaled, and max conflates {1} with {1, 1, 1}, throwing away exactly the multiplicity information 1-WL's hash preserves. That's why GIN's (1+ε)·hv + ∑u∈N(v) hu update, feeding into an MLP, is provably as powerful as 1-WL — it hits the ceiling that GCN, GraphSAGE, and GAT (with their mean/attention-weighted aggregations) provably fall short of.

Analogy: This mirrors why sum-pooling outperforms average-pooling for graph-level readout when you need to preserve count information (Lesson 12) — the same injectivity argument shows up twice, once inside each layer's aggregation and once in the final readout.

What 1-WL still can't see

Because GIN caps out at 1-WL, GIN inherits 1-WL's blind spots. The classic failure: any two regular graphs (every node has the same degree) with the same size can look identical to 1-WL, even when they're structurally very different — a 6-node cycle and two disjoint triangles are the standard example, worked through in the reference doc. If your task depends on distinguishing structures like that (counting triangles, detecting specific substructures, some molecular property prediction tasks), no amount of GIN depth or width will help; the information is gone at the aggregation step, not lost to undertraining.

The k-WL hierarchy and higher-order GNNs

1-WL is the bottom rung of an infinite hierarchy. k-WL tests generalize color refinement to color k-tuples of nodes instead of single nodes, refining based on how each tuple's neighborhood of tuples looks. Each step up is strictly more powerful: 2-WL can separate some pairs 1-WL cannot (including the cycle-vs-triangles example above), 3-WL separates some pairs 2-WL cannot, and so on.

Morris et al. (2019, "Weisfeiler and Leman Go Neural") build the neural analogue: k-GNNs, which pass messages between k-tuples of nodes rather than single nodes, and prove k-GNNs match k-WL's expressive power exactly — the same equivalence argument as GIN ↔ 1-WL, one level up.

In practice, k-GNNs for k ≥ 3 are rarely used — the O(nk) tuple bookkeeping is prohibitive for anything but small graphs. Knowing the hierarchy exists is still valuable for reading papers: when a paper claims to "go beyond 1-WL," it's implicitly claiming to sit somewhere on this ladder (higher-order tuples, subgraph counting, or added structural features), and you can ask what it costs.

Sum, followed by an MLP, can represent an injective function over any countable multiset of neighbor features. Mean and max both collapse multisets that differ only in multiplicity (e.g. {1,1} vs {1}), throwing away information 1-WL's hash would have kept — which is why they fall short of the 1-WL ceiling.
