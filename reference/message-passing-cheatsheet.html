Message-Passing Cheatsheet

The gather → aggregate → update loop from Lesson 4, in clean notation and pseudocode. Every GNN variant in this course (GCN, GraphSAGE, GAT, GIN) is this same loop with a specific choice of MSG, AGG, and UPD plugged in.

The three-step loop

For each node i, at layer k, using its neighborhood N(i):

Step Notation In words
1. Message mj→i(k) = MSG(hi(k−1), hj(k−1), eij) Compute one message per neighbor j ∈ N(i)
2. Aggregate ai(k) = AGG({mj→i(k) : j ∈ N(i)}) Combine the messages into one vector — must be permutation-invariant
3. Update hi(k) = UPD(hi(k−1), ai(k)) Fold the aggregate into the node's own previous state

hi(0) = xi, the raw input feature from X (Lesson 1). Stacking k layers of this loop produces hi(k), the representation used by whichever prediction head (Lesson 3) sits on top.

Pseudocode

for k in range(1, L + 1):          # one iteration per GNN layer
    for i in V:                    # every node, in parallel
        messages = [MSG(h[i], h[j], e[i, j]) for j in N(i)]
        a[i] = AGGREGATE(messages)      # sum / mean / max — permutation-invariant
        h[i] = UPDATE(h[i], a[i])

Common aggregators

AGG Formula Keeps Loses
Sum Σj∈N(i) mj Neighbor-count (degree) information Unbounded scale with degree
Mean (1/|N(i)|) Σj∈N(i) mj A degree-normalized average signal How many neighbors contributed
Max maxj∈N(i) mj (elementwise) The single most salient neighbor signal Every other neighbor's contribution

Common message and update functions

Function Typical form Used by
MSG mj→i = W·hj (linear transform of the sender) GCN
MSG mj→i = αij·(W·hj) — attention-weighted GAT (Lesson 9)
UPD hi' = σ(Wself·hi + ai) — self term plus aggregate, nonlinearity GCN, GraphSAGE

Note: whether the "self term" (a node's own previous embedding hi) is folded in via UPD or via a self-loop added to edge_index (Lesson 2) is an implementation choice — both accomplish the same thing, and GCN (Lesson 7) does it with self-loops.
