GNN Glossary

Quick-reference definitions for GNN terminology, covering Lessons 1–23. Grouped roughly by the module that introduces each term.

Graph fundamentals

Graph G = (V, E, u)
A data structure consisting of nodes (V), edges (E), and optional global attributes (u). Each component can carry a feature vector.
Node (vertex)
An entity in the graph. Carries a feature vector xi ∈ ℝd.
Edge
A connection between two nodes. Can be directed or undirected. Can carry a feature vector eij ∈ ℝd.
Adjacency matrix
A matrix A ∈ {0,1}|V|×|V| where Aij=1 if an edge exists from node i to node j.
Neighborhood N(i)
The set of nodes directly connected to node i by an edge.
Degree
The number of edges incident to a node. For directed graphs: in-degree and out-degree.
Sparse graph
A graph where |E| << |V|² — the vast majority of possible node pairs are unconnected. Almost all real-world graphs are sparse, which is why dense adjacency matrices are avoided in practice.
Edge list / COO format
A sparse representation of connectivity that stores only the (source, target) pairs that have an edge, rather than the full adjacency matrix. In PyTorch Geometric, this is the edge_index tensor of shape [2, |E|].
Self-loop
An edge (i, i) added from a node to itself, so that a node's own features are included when it aggregates messages from its neighbors. Not part of the original graph — added deliberately at data-processing time.
Batching (graph batching)
Combining multiple graphs into one training batch by forming their disjoint union — a single larger graph with no edges between the original graphs — plus a batch vector recording which original graph each node came from.

GNN concepts & prediction tasks

Permutation equivariance
A function f is permutation equivariant if reordering the input nodes produces the same reordering in the output: f(Px) = Pf(x). The graph analogue of translation equivariance in CNNs.
Permutation invariance
A function f is permutation invariant if the output is unchanged by node reordering: f(Px) = f(x). Required for graph-level predictions.
Node-level prediction
Predict a label or value per node (e.g., classifying users in a social network).
Edge-level prediction
Predict a label or value per edge (e.g., link prediction, bond type classification).
Graph-level prediction
Predict a label or value for the entire graph (e.g., molecular property prediction). Requires a readout/pooling step to aggregate node representations.
Node embedding hi
The learned hidden representation of node i after one or more message-passing layers, as distinct from its raw input feature xi. hi(0) = xi.
Pairwise scoring function (link prediction)
A function that combines two node embeddings into a single score for whether an edge exists or what its type is — e.g. dot product hi·hj, bilinear hiTWhj, or concat+MLP.
Readout / pooling function
A permutation-invariant function mapping the set of final node embeddings {hv} to a single graph-level vector hG. Sum, mean, and max are the standard parameter-free choices; sum uniquely preserves multiset cardinality (node count) information. See Hierarchical pooling below for a learned, multi-layer alternative.

Message passing

Message function (MSG)
The learned function computing what a neighbor j sends to node i during one message-passing layer: mj→i = MSG(hi, hj, eij).
Aggregation function (AGG)
The permutation-invariant function combining all incoming messages at a node into one fixed-size vector (e.g. sum, mean, max). Must be order-independent because a node's neighbor set has no canonical ordering.
Update function (UPD)
The learned function combining a node's own previous state with its aggregated incoming messages to produce its new state: hi' = UPD(hi, ai).
k-hop neighborhood
The set of nodes reachable from node i within k edge-traversals. After k message-passing layers, hi(k) is generically a function of exactly this set.
Receptive field (GNN)
The set of nodes that can possibly influence a given node's embedding after k layers — its k-hop neighborhood. Direct graph analogue of a CNN pixel's receptive field growing with stacked convolutional layers.
Over-smoothing
The tendency of node embeddings to become indistinguishable as GNN depth increases, because repeated neighbor-averaging acts as a low-pass (Laplacian smoothing) filter that erodes the high-frequency signal separating nodes. Named and formalized by Li, Han & Wu (2018).
Residual / skip connection (GNN)
A connection that re-injects an earlier-layer or the original (layer-0) node embedding at each layer, preventing repeated smoothing from fully washing out the identity signal. Used in GCNII's initial-residual design.
PairNorm
A normalization layer applied after each message-passing layer that rescales node embeddings to keep total pairwise distance between nodes roughly constant, directly counteracting embedding collapse (Zhao & Akoglu, 2019).
DropEdge
A regularization technique that randomly removes a fraction of edges at each training step, slowing the rate of over-smoothing while also acting as data augmentation (Rong et al., 2020).

Architectures

Spectral graph convolution
A graph convolution defined by filtering a signal in the eigenbasis of the graph Laplacian (its "graph Fourier" basis). Exact spectral convolutions require an O(|V|³) eigendecomposition and produce non-localized filters; GCN's propagation rule is derived by truncating this to a first-order, spatially-localized approximation.
Degree normalization
Scaling an aggregation step by node degree so that high-degree neighbors don't dominate the aggregated signal purely by having more edges. GCN's specific form, D̃−1/2ÃD̃−1/2, normalizes symmetrically by both the sender's and receiver's degree.
Transductive learning
A learning setting where the model is trained and evaluated on one fixed graph (or dataset) known in full at training time. GCN, as originally proposed, is transductive: its propagation rule is tied to a specific graph's adjacency and degree matrices. In practice for node classification, this means train/validation/test nodes all sit in the same graph during training — their features and edges remain visible to message passing throughout, and only their labels are masked from the loss (unlike i.i.d. splits, where test examples are physically absent from training data).
Inductive learning
A learning setting where the model generalizes to nodes, edges, or entire graphs not seen during training. Requires learning parameters as functions of local structure and features rather than as a lookup table tied to one fixed graph. GraphSAGE was designed explicitly for this setting.
Attention coefficient
A learned, content-dependent weight a node assigns to a neighbor's message, computed from both nodes' features (e.g. GAT's eij = LeakyReLU(aT[Whi ‖ Whj]), normalized via softmax into αij). Contrasts with GCN's fixed, structure-only weighting.
Injective aggregation
An aggregation function that maps every distinct multiset of neighbor features to a distinct output, with no information loss. Sum aggregation, combined with an MLP, can be injective; mean and max provably cannot (e.g. mean cannot distinguish {1,1} from {1,1,1}). GIN uses this property to match WL-test expressiveness.

Pooling, training & shallow embeddings

Hierarchical pooling (DiffPool)
A pooling approach that coarsens a graph across several layers via learned, differentiable soft cluster assignments, rather than pooling all nodes flat in one step. Trained end-to-end with the rest of the GNN. Introduced by Ying et al. (2018).
Negative sampling
Manufacturing node pairs with no edge between them (negative examples) to pair against real edges (positive examples), since a graph only records positive facts. Used to train link-prediction losses such as binary cross-entropy or margin/ranking losses.
Self-supervised learning (on graphs)
Training an encoder using signal derived from the graph's own structure and features — e.g. predicting held-out edges, or contrasting a node's embedding against a global graph summary (Deep Graph Infomax) — rather than external labels. Useful when labels are scarce.
Shallow embedding
A node representation stored as a single row of a directly-learned lookup table Z ∈ ℝ|V|×d, indexed by node ID, with no dependence on node features or a shared encoding function. DeepWalk, node2vec, and LINE are the canonical examples, predating GNN encoders.
Random walk (graph)
A sequence of nodes generated by repeatedly hopping from the current node to one of its neighbors (uniformly, as in DeepWalk, or with bias, as in node2vec). Used as a "sentence" of node IDs for skip-gram-style training.
Skip-gram objective
A training objective, borrowed from word2vec, that predicts nearby items in a sequence from a center item's embedding. Applied to graphs by treating nodes that co-occur within a random-walk window as "nearby," training embeddings so co-occurring nodes end up similar.

Expressiveness & theory

Weisfeiler-Leman (WL) test / 1-WL
A classical graph-isomorphism heuristic, also called color refinement: iteratively recolor each node by hashing its own color with the multiset of its neighbors' colors, until the coloring stabilizes, then compare final color histograms. Differing histograms prove non-isomorphism; matching histograms are inconclusive. Serves as a provable upper bound on the expressiveness of any standard message-passing GNN — no such GNN can distinguish two graphs 1-WL cannot. GIN reaches this bound exactly via injective sum-aggregation.
WL-equivalence
Two graphs are WL-equivalent if 1-WL cannot distinguish them (their final color histograms match). A message-passing GNN can never separate WL-equivalent graphs, regardless of training.
k-WL hierarchy
A sequence of increasingly powerful isomorphism tests: k-WL colors k-tuples of nodes rather than single nodes. Each level is strictly more discriminative than the last. k-GNNs (Morris et al., 2019) are the neural analogue, matching k-WL's power exactly, at O(nk) cost.
Over-squashing
The distortion of long-range information in a GNN as it's compressed through an exponentially growing number of multi-hop paths into fixed-size node vectors. Distinct from over-smoothing, though both worsen with depth and graph topology (e.g. narrow bottlenecks in the graph).
Geometric deep learning
A unifying framework (Bronstein, Bruna, Cohen, Veličković, 2021) describing architectures by the domain they operate on (grid, graph, manifold, …), the symmetry group that domain admits, and the invariance/equivariance the architecture's layers respect under that group. CNNs, GNNs, and Transformers are all instances of the same blueprint with different groups.
Group equivariance
A function is equivariant to a symmetry group if transforming the input by a group element produces the correspondingly transformed output. Permutation equivariance (graphs) and translation equivariance (grids/CNNs) are both instances of this general property under different groups.
Graph transformer
An architecture that applies Transformer-style full self-attention (every node attends to every other node) to graph-structured data, typically combined with positional/structural encodings and, in hybrid designs like GraphGPS, a parallel sparse message-passing path.
Positional encoding (graph)
Extra per-node features added before attention to inform a graph transformer about graph structure, since full attention on its own is blind to edges. Common schemes include Laplacian eigenvector PE (global structural position, from the graph Laplacian's eigenvectors) and random-walk PE / RWPE (local structural role, from k-step random-walk return probabilities).

Heterogeneous & knowledge graphs

Heterogeneous graph
A graph with more than one node type and/or more than one edge (relation) type, each carrying its own semantics — e.g., Author/Paper/Venue nodes connected by writes/cites/published_in edges. A strict generalization of the single-type graphs used in Modules 1–5.
Relation-specific weight matrix
A weight matrix Wr learned separately for each relation type r, so that a heterogeneous GNN doesn't force semantically different edges (e.g., "cites" vs "writes") through the same transformation. Used in R-GCN; regularized via basis or block-diagonal decomposition to control parameter growth as the number of relations grows.
Meta-path
A hand-specified composite relation over a heterogeneous graph's schema, e.g. Author–Paper–Author for co-authorship. Used by HAN to define homogeneous neighborhoods for attention; HGT avoids requiring these by attending over meta-relation triplets instead.
Knowledge graph
A heterogeneous graph where every edge is a fact, written as a triple (head entity, relation, tail entity). The dominant task is knowledge graph completion — predicting plausible missing triples.
Knowledge graph embedding (KGE)
A family of "shallow" (non-message-passing) methods that learn a vector per entity and per relation, optimized so a scoring function f(h, r, t) is high for true triples and low for corrupted ones. TransE, DistMult, and ComplEx are the canonical examples.
TransE scoring
Scores a triple by how close h + r lands to t: score(h,r,t) = −‖h + r − t‖. Cheap and effective for one-to-one relations, but structurally unable to represent symmetric or many-to-many relations well.
DistMult scoring
A bilinear scoring function score(h,r,t) = hTdiag(r)t, with each relation represented as a diagonal matrix (vector). Symmetric in h and t by construction, so it cannot represent antisymmetric relations (e.g., parent_of).
ComplEx scoring
A bilinear scoring function over complex-valued entity and relation embeddings, score(h,r,t) = Re(∑ hi ri conj(ti)). The conjugate on the tail breaks DistMult's h/t symmetry, letting ComplEx represent both symmetric and antisymmetric relations.

Temporal & dynamic graphs

Discrete-time (snapshot) dynamic graph
A dynamic graph observed as a sequence of static graphs G1…GT at fixed intervals. Time is a coarse index; timing differences within a snapshot window are lost. EvolveGCN operates in this setting.
Continuous-time (event-stream) dynamic graph
A dynamic graph observed as a stream of individually timestamped, irregularly-spaced events with no binning. The natural framing for transaction data. TGAT, TGN, and DyRep all operate in this setting.
Temporal memory module
A persistent per-node vector (used in TGN) that summarizes a node's event history, updated incrementally via a message function and a recurrent memory updater (e.g., GRU) each time a new event touches that node — avoiding the need to rescan full history at query time.
Functional time encoding
A learned mapping from a continuous time delta into a feature vector, grounded in Bochner's theorem, used by TGAT to make self-attention over a temporal neighborhood time-aware — conceptually similar to positional encoding in sequence Transformers, but continuous and learned.

Fraud & AML

Class imbalance (fraud/AML)
The condition where confirmed fraud or laundering activity makes up a tiny fraction of all transactions, so naive accuracy-optimizing models learn to predict "legitimate" for everything. Requires resampling, reweighted/focal losses, or fraud-aware sampling rather than standard cross-entropy training.
Relation camouflage / heterophily (fraud graphs)
The tendency of fraudulent nodes to deliberately transact with legitimate ones to blend in, producing neighborhoods where a fraud node's immediate neighbors are disproportionately legitimate — the opposite of the homophily assumption many GNN architectures (e.g., plain GCN) implicitly rely on.
Fan-in / fan-out / cycle (AML motifs)
Structural transaction patterns associated with money-laundering typologies: fan-in (many accounts feeding one — placement/smurfing), fan-out (one account rapidly distributing to many — distribution), and cycles (funds routed back toward their origin through intermediaries — layering). Visible only at the subgraph level, not from any single transaction's features.

Generative models & LLMs

Graph generation (deep generative models for graphs)
The task of learning to produce new, plausible graphs from a training distribution of graphs, rather than predicting labels on a fixed input graph.
Graph matching (permutation alignment)
An algorithm that searches for the node permutation of one graph that best aligns it to another, used to compute a meaningful reconstruction loss between a generated graph and a target graph when neither has a canonical node ordering.
GraphVAE
A variational autoencoder for graphs (Simonovsky & Komodakis, 2018) whose decoder outputs a full probabilistic adjacency and feature matrix at once, using an approximate graph-matching step to compute reconstruction loss. Limited in practice to small graphs due to O(n²) output size and roughly O(n⁴) matching cost.
Autoregressive graph model
A generative model that builds a graph sequentially — adding one node and its edges at a time, conditioned on the graph built so far — rather than producing the whole structure in one shot.
GraphRNN
An autoregressive graph generator (You et al., 2018) using a graph-level RNN to add nodes and an edge-level RNN to decide edges to prior nodes as Bernoulli draws. Trains on a BFS node ordering, which bounds each edge decision to a recent window and lets it scale to much larger graphs than GraphVAE.
Graph-to-text serialization
Converting a graph's structure (nodes, edges, features) into a natural-language or structured text prompt so a large language model can reason over it directly, without a GNN.
Text-attributed graph
A graph whose nodes (or edges) carry natural-language text — e.g. paper abstracts, product descriptions — which must be embedded into a feature matrix before a GNN can consume it.
LLM–GNN integration paradigms (Enhancer / Predictor / Alignment)
A taxonomy for how LLMs and GNNs are combined: LLM as Enhancer (LLM improves node/edge features fed into a GNN), LLM as Predictor (LLM makes the final prediction from a graph serialization), and GNN–LLM Alignment (the two are trained jointly in a shared representation space).
GraphRAG
A retrieval-augmented generation approach that builds a knowledge graph from a text corpus, clusters it into communities with summaries, and retrieves along that graph structure (in addition to or instead of flat embedding similarity) to ground LLM generation — especially useful for questions whose answer is scattered across many documents.
