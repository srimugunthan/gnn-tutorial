WL Test Reference

The 1-dimensional Weisfeiler-Leman (1-WL) test, a.k.a. color refinement, step by step — with a worked example it solves and a worked example it can't. Companion to Lesson 15.

The algorithm

  1. Initialize. Give every node v a color c(0)(v). If nodes carry labels, start from those; otherwise start from degree.
  2. Refine. At each round t, recolor every node by hashing its current color together with the multiset of its neighbors' current colors: 
    c^(t+1)(v) = HASH( c^(t)(v),  {{ c^(t)(u) : u ∈ N(v) }} )
    The double braces mean multiset — duplicates matter, order doesn't. HASH just needs to be injective (map different inputs to different outputs); its exact form doesn't matter for the test.
  3. Stop. Repeat until the coloring stabilizes — no node's color changes in a round. This takes at most |V| − 1 rounds.
  4. Compare. Run refinement on both graphs at once (so the same HASH assigns consistent colors across both). If the final color histograms (color → count) differ, the graphs are definitely non-isomorphic. If the histograms match, the test is inconclusive — the graphs might be isomorphic, or might not be; 1-WL simply can't tell.
Key idea: 1-WL never proves two graphs are isomorphic — it can only prove they're not, by finding a difference in the final histograms. A matching histogram is a "maybe," not a "yes."

Worked example: a pair 1-WL distinguishes

Two 5-node graphs with the same degree sequence {3, 2, 2, 2, 1} — so comparing initial degree histograms alone is inconclusive. Refinement is needed.

Round 0 (degree): both graphs give the histogram {3:1, 2:3, 1:1}. Identical — inconclusive so far.

Round 1 recolors each node by hashing its degree with the multiset of its neighbors' degrees. Focus on the degree-3 hub in each graph:

  • Node 1 (Graph A) neighbors are 2 (deg 2), 4 (deg 2), 5 (deg 1) → neighbor multiset {2, 2, 1}
  • Node 1′ (Graph B) neighbors are 2′ (deg 2), 3′ (deg 2), 4′ (deg 2) → neighbor multiset {2, 2, 2}

Different neighbor multisets → the hash gives node 1 and node 1′ different new colors. Working through the rest of the nodes the same way, the two degree-1 nodes also end up differently colored (node 5's only neighbor has degree 3; node 5′'s only neighbor, 4′, has degree 2). By round 1, the color histograms of A and B no longer match. 1-WL correctly certifies A and B are non-isomorphic — which is visible directly too, since A contains a 4-cycle and B doesn't.

Worked example: a pair 1-WL can't distinguish

Every node in both graphs starts with the same color (degree 2). At round 1, every node's neighbor multiset is also identical — two neighbors, each colored "degree 2" — so every node hashes to the same new color again, in both graphs. Nothing ever differentiates any node from any other, in either graph or across graphs. The final histograms are identical: {single-color: 6} for both. 1-WL is inconclusive, even though the graphs are obviously not isomorphic (one is a single 6-cycle, the other is two disconnected components).

Key idea: This failure is structural, not a matter of running more rounds. Once every node in a graph looks identical to color refinement (as happens for any regular graph where local neighborhoods are all alike), no further round of hashing can introduce a difference. The 2-WL test can tell C6 and 2×C3 apart, because it colors node pairs and can detect that C6 has pairs at graph-distance 3 while 2×C3's farthest pairs (within a triangle) are at distance 1.

Why this matters for GNNs

As Lesson 15 covers, message passing is color refinement with a learned hash. GIN reaches the 1-WL ceiling; GCN, GraphSAGE, and GAT sit somewhere below it because their aggregation functions (mean, attention-weighted mean) aren't injective over neighbor multisets. Either way, every message-passing GNN inherits the C6-vs-2×C3 blind spot: no amount of training will let a GIN distinguish two graphs that look identical to color refinement.
